1. Conociendo la plataforma

¿Qué es Visual Studio y quién lo hizo?

Es un programa de la empresa Microsoft que sirve para crear otros programas. En un solo lugar se escribe el código, se diseña cómo se ve la aplicación, se prueba y se corrigen los errores. A eso se le llama IDE (entorno de desarrollo integrado).

¿Qué es Visual Studio Community?

Es la versión gratis para estudiantes, personas que programan por su cuenta, proyectos de código abierto y equipos pequeños.

¿Es gratis? ¿Es de código abierto?

Community es gratis, pero tiene condiciones: las empresas grandes tienen que pagar otra versión. No es de código abierto, porque es un programa de Microsoft con dueño.

Visual Studio y Visual Studio Code

Se parecen en el nombre pero son distintos:

Visual StudioVisual Studio Code
Qué esPrograma completo y grandeEditor de código liviano
Funciona enWindowsWindows, Mac y Linux
Sirve paraProyectos grandes con ventanas y diseñadoresProyectos rápidos y páginas web

¿Qué lo hace profesional?

  • Sugiere código mientras uno escribe (autocompletado).
  • Tiene un depurador para buscar errores.
  • Tiene diseñadores para armar ventanas.
  • Se conecta con Git, GitHub y bases de datos.

4. Complementos y extensiones

Las extensiones y cargas de trabajo son piezas que se instalan para que Visual Studio haga más cosas. Se escogen en el instalador y así solo se instala lo que se necesita.

  • Python: para programar y correr código en Python.
  • .NET MAUI: para hacer una app que funcione en celular y computadora.
  • Desarrollo con C++: trae lo necesario para programar en C++.
  • Git y GitHub: para guardar el proyecto y trabajar en equipo sin perder cambios.
  • Herramientas de bases de datos: para ver las tablas y los datos.
  • Depuración y diagnóstico: para encontrar errores y ver por qué un programa va lento.
  • Diseñador de Windows Forms: para armar ventanas arrastrando botones.

5. Herramientas para diseñar aplicaciones

Interfaz gráfica: es lo que el usuario ve y toca en un programa: ventanas, botones y menús.

Formularios: son las ventanas de la aplicación.

Controles visuales: son las piezas que se ponen en el formulario, como botones (Button), cuadros de texto (TextBox), listas (ListBox) y menús (MenuStrip).

Cómo se agregan: se abre el Cuadro de herramientas, se arrastra el control al formulario y se cambian sus propiedades, como el nombre y el texto. Con doble clic en un botón se escribe lo que hace al presionarlo.

Depurador: sirve para encontrar errores. Pausa el programa en una línea, permite avanzar paso a paso y muestra el valor de las variables.

6. Bases de datos y aplicaciones

SQL es el lenguaje que se usa para guardar y pedir datos en una base de datos. SQL Server es el programa de bases de datos de Microsoft. También se puede trabajar con MySQL y con SQLite, que guarda todo en un solo archivo y es muy fácil de usar.

Desde una aplicación se hacen cuatro cosas con los datos:

AcciónInstrucción SQL
RegistrarINSERT
ConsultarSELECT
ModificarUPDATE
EliminarDELETE

Ejemplo en Python con SQLite:

import sqlite3
conexion = sqlite3.connect("inventario.db")
cursor = conexion.cursor()

cursor.execute("INSERT INTO productos (nombre, precio, cantidad) VALUES (?, ?, ?)",
               ("Arroz", 50, 10))
conexion.commit()

cursor.execute("SELECT * FROM productos")
print(cursor.fetchall())

7. Ventajas y limitaciones

Ventajas

  • Es gratis para estudiantes y equipos pequeños.
  • Tiene todo en un solo lugar.
  • Su depurador es muy bueno.
  • Sirve para muchos lenguajes y sistemas.
  • Se conecta con GitHub y bases de datos.
  • Tiene mucha ayuda en la página de Microsoft.

Limitaciones

  • Gasta bastante memoria y se pone lento en computadoras flojas.
  • Solo funciona en Windows.
  • Las empresas grandes no pueden usar la versión gratis.

Una empresa o un programador lo elegiría porque ahorra tiempo al tener todo junto y porque hay mucha ayuda para aprender.

8. Nuestro primer proyecto: sistema de ventas e inventario

Imaginamos que una empresa nos contrata para hacer un programa para una tienda o colmado. Este es el proyecto completo que hicimos. La investigación es sobre Visual Studio Community, pero el programa lo hicimos en Visual Studio Code porque es más liviano y funciona bien con Python. Python también se puede usar en Visual Studio con su carga de trabajo.

¿Qué problema resuelve?

Muchos negocios pequeños llevan el inventario en un cuaderno o en Excel. Se pierden hojas, se cuentan mal los productos y a veces el dueño se entera de que algo se acabó cuando un cliente lo pide. Nuestro programa anota las ventas, resta solo lo que se vende y avisa cuando queda poquito.

¿Quiénes lo usarían?

  • Administrador (el dueño): puede hacer todo.
  • Vendedor: agrega, ve y vende productos, pero no puede borrar.

¿Qué funciones tiene?

  • Entrar con usuario y contraseña.
  • Agregar, ver, cambiar y borrar productos.
  • Vender, calcular el total y guardar la venta.
  • Restar del inventario lo que se vendió.
  • Avisar de los productos con poco stock.
  • Crear usuarios nuevos (solo el administrador).

¿En qué sistema funciona y con qué lenguaje?

Funciona en Windows. Usamos Python porque es fácil de aprender y se lee casi como inglés, y SQLite para la base de datos porque viene incluida con Python y guarda todo en un solo archivo (inventario.db). No hay que instalar nada extra.

¿Qué herramientas necesitamos?

Usamos Visual Studio Code con la extensión de Python de Microsoft, el depurador, Git y GitHub, y una extensión de SQLite para ver la base de datos.

¿Qué guarda la base de datos?

TablaQué guarda
usuariosUsuario, contraseña y rol (admin o vendedor)
productosNombre, precio, cantidad y cantidad mínima

CREATE TABLE productos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  nombre TEXT NOT NULL,
  precio REAL NOT NULL,
  cantidad INTEGER NOT NULL,
  minimo INTEGER DEFAULT 5
);

Cómo funciona el programa

Al abrirlo pide usuario y contraseña (la primera vez es admin y 1234). Después sale un menú con números: 1 agregar, 2 ver, 3 cambiar cantidad, 4 borrar, 5 vender y 6 ver stock bajo. El administrador también ve la opción 7 para crear usuarios.

Así se hace una venta:

  1. El vendedor elige la opción 5.
  2. El programa muestra la lista de productos con su ID.
  3. Escribe el ID del producto (no el precio) y cuántos va a vender.
  4. El programa revisa que haya suficiente. Si no hay, dice que no hay suficiente stock.
  5. Si hay, resta la cantidad, calcula el total y guarda la venta.

Este es el código que vende:

def vender(id, cantidad_vendida):
    cursor.execute("SELECT precio, cantidad FROM productos WHERE id = ?", (id,))
    producto = cursor.fetchone()
    if producto is None:
        print("Ese producto no existe")
        return
    precio, hay = producto
    if hay >= cantidad_vendida:
        total = precio * cantidad_vendida
        cursor.execute(
            "UPDATE productos SET cantidad = cantidad - ? WHERE id = ?",
            (cantidad_vendida, id))
        conexion.commit()
        print("Venta hecha. Total:", total)
    else:
        print("No hay suficiente stock")

Y esta consulta busca los productos que se están acabando:

SELECT nombre, cantidad FROM productos WHERE cantidad <= minimo;

Cómo lo probamos

Usamos el depurador para ir línea por línea. Probamos vender más de lo que hay, dejar campos vacíos y escribir letras donde van números. El programa avisa del error en vez de dañarse.

Cómo se usa

  1. Instalar Python (marcando Add Python to PATH) y Visual Studio Code con la extensión Python.
  2. Crear una carpeta y poner dentro el archivo inventario.py.
  3. Abrir la carpeta en el editor y darle al botón de play.
  4. Entrar con admin y 1234.

Lo que podríamos mejorar

  • Guardar las contraseñas cifradas, porque ahora se guardan como texto normal.
  • Hacerle ventanas con botones con Tkinter.
  • Agregar lector de código de barras e imprimir facturas.
  • Hacer una versión para el celular.

Conclusión

Un programador no solo escribe código: también tiene que saber diseñar, probar y corregir. Con este trabajo aprendimos que Visual Studio ayuda con todo eso y que con un proyecto como el inventario se puede resolver un problema real de un negocio.
